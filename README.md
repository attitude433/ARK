# ARK

마인크래프트 **NeoForge 1.21.x** 기반 RPG 모드. **데이터팩 주도(data-driven)** 설계 — 모드는 시스템·코덱·엔진을 제공하고, 콘텐츠는 데이터팩 JSON으로 정의한다.

> 상태: **게임 디자인 진행 중** (구현 전)

## 비전

- 장르: **전투·스킬 중심의 액션 RPG** + **"살아있는 세계"**(유기적으로 반응하는 세계)
- 제작 철학: 욕심내지 않고 **한 단계씩**. 가장 작은 수직 슬라이스부터 끝까지 굴린 뒤 위에 얹는다.
- 모드 ID: `ark` · 데이터팩 경로: `data/ark/...`

## 핵심 시스템 (설계 요약)

- **스탯**: 기본 3종(힘·민첩·지능) → 하위 6종(공격/인내·신속/숙련·마력/제압)에 레벨업 포인트 투자. 정수값. 별도 특수 스탯 **침식**(세계관으로 상승, 마수화).
- **성장**: 레벨 +1마다 포인트 3개, 경험치·레벨 영구 유지.
- **자원**: 마나(전체 지능 비례, 전투 외 빠른 재생).
- **클래스**: 삼각 방사형 트리 — 기본 3클래스(전사·도적·마법사) × 각 3갈래 = 9빌드 + 공개 하이브리드 3변(궁수·마검사·주술 검객). 스탯 문턱으로 해금, 단일 활성, 리스펙으로 변경.
- **무기**: 클래스→허용 무기→스킬. 필요 스탯(미달 시 소프트 페널티). 무기 공유 원칙.
- **스킬**: 데이터팩 정의. 마나+쿨다운. 즉발 5키 + Alt 라디얼 휠. 공격력/마법력 가중치 스케일. 효과 부품 조합.
- **마수/침식**: 변신(마수화) 시스템 — 발동 토글, 허기로 유지, 사냥 루프. (세부 해금은 세계관과 함께 추후.)
