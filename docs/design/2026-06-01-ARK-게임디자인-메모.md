# ARK — 게임 디자인 메모

> 마인크래프트 NeoForge 1.21.x RPG 모드
> 작성: 2026-06-01 (갱신: 2026-06-03) · 상태: **게임 디자인 — 큰 틀 잡는 중**
> 이 문서는 정식 스펙이 아니라 **결정 사항 기록용 메모**입니다. 계속 늘고 줄어듭니다.

---

## 1. 큰 방향

- 장르: **전투·스킬 중심의 액션 RPG** + **"살아있는 세계"**(유기적으로 반응하는 세계)
- 제작 철학: 욕심내지 않고 **한 단계씩**. 가장 작은 것부터 끝까지 굴린 뒤 위에 얹는다.
- 기술 기반: **NeoForge 1.21.x**, **데이터팩 주도 설계** (모드는 시스템·코덱·엔진을 제공, 콘텐츠는 데이터팩 JSON으로 정의)
- 모드 ID: `ark` (브랜드 표기 "ARK"), 데이터팩 경로 `data/ark/...`

### 분해 & 제작 순서 (의존 사슬)

```
[기반] 전투 & 스킬 코어 (스탯이 출발점)
   └→ [A] 살아있는 생태계
        ├→ [B] 평판/결과
        └→ [C] 시스템 상호작용
             └→ [D] 동적 월드 진행
```

→ **첫 슬라이스 = 스탯 시스템 코어.** 생태계·평판 등은 그 위에 데이터/모듈로 얹는다.

### 아키텍처 방향 (스탯 엔진)

- **하이브리드 접근**: 1차 능력치는 데이터 주도 커스텀, 파생 효과는 가능한 한 바닐라/커스텀 **Attribute 모디파이어**로 적용(바닐라와 자동 연동), 표현 불가한 것만 엔진이 직접 처리.
- 비유: *모드 = 어휘, 데이터팩 = 문장, 필요하면 코드로 어휘 확장.*
- 저장: 플레이어별 **Data Attachment** (NBT 영속화 + 클라 동기화).

## 2. 확정된 설계

### 2.1 1차 능력치 (내적 능력 · 정수값 · 레벨업 포인트로 성장)

| 능력치 | 효과 | 성격 |
|---|---|---|
| **힘 (STR)** | **공격**(→공격력) / **인내**(→체력) | 묵직한 한 방, 단단함 |
| **민첩 (DEX)** | **신속**(→이동속도) / **숙련**(→공격속도) | 빠르게 자주 |
| **지능 (INT)** | **마력**(→마법뎀) / **제압**(→제압 위력·효과 지속시간) | 스킬·마법의 길 |

> **※ 침식(erosion)은 기본 스탯이 아님 — 별도 특수 스탯.** 레벨업 포인트로 올리지 않고 **세계관 관련 방식으로 상승**(추후 설계). 마수화(변신)를 다스리는 힘. 침식/마수는 *3개 기본 클래스 위에 얹히는 특수 레이어*(추후 별도 설계). 변신 안 하면 무능력 등 변신 메커니즘은 §2.4 유지.

> **스탯 세분화(2단 분화):** 클래스 내 차별화를 위해 1차 능력치를 하위 2갈래로 쪼개 *따로 투자*. 1차는 여전히 클래스 뿌리(우산)로 남아 4클래스 구조 유지.
> - **힘** → **공격**(공격력) / **인내**(체력) ✅
> - **민첩** → **신속**(이동 속도) / **숙련**(공격 속도) ✅
> - **지능** → **마력**(마법뎀) / **제압**(제압=군중제어·디버프 위력 + 버프/디버프 효과 지속시간) ✅
>   - **마나는 하위 스탯에서 분리 → "자원"**으로 전체 지능 투자량에 비례(우산). (마나는 "특징"이 아니라 자원이라 하위 스탯에서 뺌.)
> - **침식은 기본 스탯에서 제외** (별도 특수 스탯, 세계관으로 상승 — 위 ※ 참고).
>
> → **포인트 투자 대상 = 하위 스탯 6종**(공격·인내·신속·숙련·마력·제압). 레벨업 포인트 3개를 이들에 분배. 클래스 가지는 어떤 하위 스탯을 얼마나 찍느냐로 갈라짐. (침식은 포인트 투자 대상 아님.)

- 비율·구체 수치는 전부 **추후 밸런싱**.

### 2.2 성장

- 바닐라 경험치 **레벨 +1마다 스탯 포인트 3개** 영구 적립 → **하위 스탯 6종(공격·인내·신속·숙련·마력·제압)에 자유 분배.** (침식은 포인트 투자 대상 아님 — 세계관으로 상승.)
- **경험치·레벨은 영구 유지** (죽음 등으로 손실 없음 — 바닐라 손실 동작을 덮어씀).
- 적립 포인트·분배값은 현재 경험치 레벨과 **분리** 저장. (레벨이 안 깎이므로 받은 포인트 = 레벨 × 3.)
- 포인트 분배용 **전용 화면** 필요 (기능만 확정, 비주얼은 추후).
- **리스펙(재분배) = 가능, 단 특정 아이템 소모.** 아이템 출처 = **퀘스트/보스 보상**.
  - 개발 중엔 명령어/크리에이티브로 아이템 지급해 테스트, 정식 배치는 콘텐츠 단계.
- **레벨업 페이싱 = 메인 퀘스트 라인이 페이서.** 클래스 해금(10레벨)까지의 *메인 퀘스트 라인*이 자연스럽게 페이싱을 잡도록 설계 — 시간 기준이 아니라 *서사·콘텐츠 기준*. 따라서 "레벨당 3pt" 비율은 그대로 유지, 바닐라 XP도 그대로 (퀘스트 보상 + 진행 중 잡몹·채집 XP가 합쳐서 자연스러운 속도). 정밀 밸런스는 메인 퀘스트 시스템 추가 시점에 검증.
- **캐릭터 최대 레벨 = 50.** 50레벨 × 3pt = **총 150 포인트 적립**. 한 스탯에 *몰빵 만렙*도 150pt까지 가능 → 하위 스탯 **max = 150**으로 통일. (메인 퀘스트 끝나는 시점과 맞춰질 예정 — 구체 페이싱은 메인 퀘스트 시스템 시점에 검증.)

### 2.3 마나

- **모든 빌드가 기본 마나 보유 + 지능이 증폭.** 지능 직업이 마나 의존도가 높음.
- 재생 = **전투 외 빠른 회복** (전투 중엔 거의 안 참 → "전투 한 판의 예산").
- 소모처 = 스킬 (스킬 시스템은 추후). 표시 = 마나 바 (비주얼 추후).
- 메모: 마크엔 "전투 중" 상태가 없으므로 **전투 상태 판정**(최근 N초 내 피해 주고받음 등)을 별도로 정의 필요.

### 2.4 침식 → 마수화 (변신 시스템)

- **발동형 변신**: 전용 키 토글. 외형은 추후.
- 유지 대가 = **허기 소모**. 가만히 있으면 허기가 닳아 풀림. 허기 바닥 시 굶주림 위험.
- **사냥 루프**: 몬스터 처치 시 허기 회복 → 계속 싸우면 변신 유지. ("굶주린 야수가 사냥으로 자신을 먹여 살린다")
- 변신 중 효과 (전부 **침식 수치에 비례**):
  - 공격력 ↑ / 체력 재생 / 처치 시 허기 회복량 / 허기 소모 속도(침식↑일수록 ↓, 오래 버팀)
- 평상시(변신 X) 패시브 없음.
- 진화: 침식이 깊을수록 더 강하고 상위 형태로 (단계형 가미).

### 2.5 클래스 (직업)

- **모델 = 명시적 클래스 (Model A).** 클래스가 정체성. **클래스 → 허용 무기 종류 → 스킬** 순서(무기가 클래스를 정하는 게 아니라, 클래스가 쓸 무기를 정함). ("무기에 따라 달라진다"는 직관은 *클래스 안 무기 종류별 스킬*로 살림.)
- **기본 클래스 = 3개 (뿌리 = 기본 스탯):**

  | 뿌리 스탯 | 기본 클래스 | 무기 결 |
  |---|---|---|
  | 힘 | 전사 | 검·도끼·둔기 |
  | 민첩 | 도적/궁수 | 단검·활 |
  | 지능 | 마법사 | 지팡이·완드 |

  - **마수/침식은 4번째 기본 클래스가 아님.** 침식(세계관으로 상승하는 특수 스탯)이 일정 수준이 되면 *3개 기본 클래스 위에 마수화(변신) 레이어*가 열림 — 별도 설계(추후). (충동/억제 같은 추상 분기는 보류.)

- **가지치기 = 어떤 하위 스탯을 찍느냐로 갈라짐** (클래스 내 차별화). 하이브리드(마검사 등)는 *별도 클래스가 아니라 가지*. 같은 클래스라도 무기 종류·하위 스탯 조합·투자량 문턱·스킬 노드 선택·책으로 다양화.
  - 예) 전사 → 공격 집중(딜러) / 인내 집중(탱커) / +신속·숙련(빠른 검사) / +마력(마검사) / +침식(마수전사)
- **하나만 활성화 가능** (여러 개가 열려도 택1). 변경은 **리스펙(스탯 초기화권)**으로 스탯 재분배 → 다른 문턱 충족 → 다른 클래스 선택. (클래스 변경이 별도 기능이 아니라 스탯 초기화에서 흘러나옴.)
- **클래스 선택 시점 = 10레벨.** 그 전엔 무클래스(포인트 적립). 클래스 해금 **최소 문턱 ≈ 한 스탯 20** (8레벨=24p로 도달 가능, 오투자 1~2회 여유분 포함). 10레벨엔 30p로 여유롭게 충족.
- **두 종류:**
  - **일반 클래스**: **스탯 문턱값으로 공개 해금** (예: 침식 N↑ → 마수 클래스 → 마수화 개방, 지능 N↑ → 마법사 계열, 힘 N↑ → 전사 계열).
  - **히든 클래스**: **비밀 조건으로 발동** (특수 스탯 조합 / 비밀 행적 / 숨겨진 퀘스트·유물 / 테마 연계 등 — 구체 트리거는 추후). 발동 시 기존 클래스 유지 vs 히든 전환 중 **택1**.
    - **한번 발동 = 영구 해금** (비밀은 다시 안 채워도 됨).
    - 단 실제 선택·사용엔 **해당 클래스 스탯 요구치 충족 필요** → 이중 관문.

### 2.7 스킬 시스템

- 스킬은 **데이터팩으로 정의** (JSON), **마나 소모** 시전, 지능이 마법 데미지를 키움. 모든 빌드가 조금씩 쓰되 지능 직업이 주력.
- **획득 3계층:**
  1. **클래스 스킬 (공개)** — 일반 클래스 트리를 타며 얻는 기본·주력 스킬.
  2. **숨겨진 스킬 (책)** — 스킬북/스크롤로만 배우는 희귀 스킬 (클래스 무관하게 수집).
  3. **히든 클래스 스킬** — 히든 클래스 발동 시 얻는 고유 스킬.
- **사용 조건 = 클래스에 맞는 무기를 들고 있어야 함.** 무기를 든 순간이 곧 "전투 태세" → 그때만 스킬 키 활성. 무기를 집어넣으면 평소 마크 조작 그대로. (→ 키 충돌·쉬프트 마찰을 자연스럽게 해소.) 클래스마다 어울리는 무기 *종류*가 있음(전사=검·도끼, 마법사=지팡이 등) — 무기 시스템에 "클래스 연계"가 추가됨. **무기 전용 스킬 없음** — 클래스 무기를 들고 있으면 어떤 무기든 모든 스킬 사용 가능.
- **입력 매핑 (즉발 스킬 5개):**

  | 입력 | 역할 |
  |---|---|
  | 좌클릭 | 평타 (마나 X, 기본 공격) |
  | 우클릭 | 1번 스킬 |
  | 쉬프트+좌클릭 | 2번 스킬 |
  | 쉬프트+우클릭 | 3번 스킬 |
  | R | 4번 스킬 |
  | C | 5번 스킬 |

- **라디얼 휠 (나머지 스킬): Alt 꾹 누르기** → 원을 가용 스킬 수만큼 파이로 분할, 마우스 드래그로 방향 선택, 원 바깥 삼각형으로 현재 가리키는 슬라이스 표시, Alt 떼면 **그 스킬 즉시 시전** (Alt 꾹 → 방향 → 떼면 발사).
- **로드아웃**: 즉발 5칸 = 빠르게 쓸 스킬(빌드 선택), 휠 = 나머지 전부. (즉발 칸에 어떤 스킬을 올릴지 선택 가능 — 추정)
- **키 매핑 원칙**: 기본값은 *누구나 가진 입력*만 사용(키보드+좌/우클릭). 마우스 옆버튼 등은 기본 제외하되, **모든 스킬 키 재설정 가능**(바닐라 조작 설정 메뉴 등록). F(오프핸드)·T(채팅)·Q(버리기)·E(인벤)는 기본값에서 회피.
- **쿨다운**: 스킬은 **마나 소모 + 쿨다운** 둘 다. 쿨다운은 스킬별로 다름(데이터팩 정의). **쿨다운 감소(쿨감)** 수단 있음 — **다양한 장비의 옵션**으로 확보.
- **스케일 구분**: 스킬 위력 = **스탯별 가중치 합** = 공격력 × a + 마법력 × b. a만 = 순수 공격력 스킬(물리·무술, 힘 빌드 주력), b만 = 순수 마법력 스킬(지능 빌드 주력), 둘 다 = **하이브리드**(마검사 등). 데이터팩에서 스킬별로 a·b 정의. 둘 다 마나+쿨다운 공통.
  - **마수/침식 스킬 = 공격력 기반.** 침식이 변신 중 공격력을 올려주므로 간접 반영됨 → 별도 침식 스케일 불필요, 스케일 축은 공격력·마법력 둘로 단순 유지.
- **스킬 효과 종류 (목표: 전부 지원):** 공격형 · 이동기 · 버프형 · 디버프형 · 회복형 · 소환형 · 설치/장판형.
  - 효과는 **배타적 분류가 아니라 조합 가능한 "부품"** — 한 스킬이 여러 효과를 가짐 (예: "돌진 베기" = 이동기+공격형). 데이터팩이 부품을 조합해 스킬 정의.
  - 설계는 전부 담되 **구현은 점진적**(공격형부터 → 확장). 엔진이 모르는 새 효과는 코드로 어휘 추가.

- **데이터팩 vs 모드 분담:** *스탯·클래스·전투수학·변신 등 고정 핵심 = 모드(코드)*. *스킬 = 데이터팩(JSON)* — 모드가 효과 부품(어휘)을 코드로 제공, 스킬 하나하나는 부품을 조합한 JSON. (스탯은 6종 고정이라 데이터팩화 불필요 → 코드.)
- **스킬 엔진 = 4축 구조** (구상 중):
  1. **부품(효과)** — 즉시/광역/투사체/관통/도트 · 돌진/순간이동/도약/끌당김/넉백 · 버프/디버프/방어막/회복 · 기절/속박/둔화/침묵 · 소환/장판/함정 …
  2. **트리거(연결)** — 한 부품의 결과가 다음을 발동 (명중 시 / 처치 시 / 종료 시 / 일정 시간 후 …)
  3. **대상·위치 지정** — 누구에게·어디에 (맞은 대상, 그 뒤, 주변, 시전자 …)
  4. **상태/누적값** — 변하는 숫자를 기억·참조 (콤보 카운터, 흡수한 피해, 차지량 — 효과 수치가 이 값을 참조해 스케일)
  - 검증 예시: "그림자 단검" = `투사체(단검)` →[명중 시]→ `순간이동(대상=맞은 적, 위치=그 뒤)`. "피해 흡수 반격" = `흡수 상태(피해를 저장값에 누적)` →[종료 시]→ `데미지 방출(=저장값)`. "콤보 마무리" = `누적값(콤보)` 비례 마무리기.

### 2.8 클래스별 스킬 목록 (구상 중)

> 스킬은 클래스당 약 10개 목표. 10레벨 클래스 선택 시 기본 스킬 1개 습득, 나머지는 **스킬 포인트로 습득**. 즉발 5칸 + 라디얼 휠 배치(§2.7).
>
> **스킬 포인트 = 침식 조각(보스 드롭)을 소모해 획득.** 단, 침식 조각은 *스킬 포인트로 쓸지 / 침식 능력치 해금에 쓸지* 플레이어가 선택(§2.5.1 세계관). → "인간의 힘(스킬)이냐 괴물의 힘(침식)이냐"의 갈림길. 리스펙 아이템은 별도 드롭(§2.2).

### 2.5.1 기본 클래스 구상 (진행 중)

**전사 (힘)** *(구상 중)* — 근접 물리. 하위 스탯(공격/인내) 투자로 가지가 갈림:
- **공격 몰빵 → 차징 특화 가지**: 폭발적 한 방. **홀드 차징**(꾹 눌러 충전 → 떼면 강타). *잠정.* **무기 (전부 공격 24 요구), 무기별 특화:**
  - **대검** → 차지 공격 보너스 (차징 정석, 단일 폭딜)
  - **큰 망치** → 기절 + 넉백 (제어)
  - **대부** → 광역 휩쓸기 (다수전)
  - 열린 점: 홀드 차징의 단조로움 보완(차징은 시그니처 강타에만 + 나머지 즉발 / 탭·홀드 분기 / 차징 단계별 효과 / 차징 중 이동) — 추후.
- **공격 + 인내 → 보편적/정통 전사 가지**: 균형 잡힌 근접 전투. 특별한 기믹 없이 딜·맷집 적당한 "기본기"형. 입문·만능. **무기 (방패는 오프핸드 별도 칸; 클래스 무기 판정은 메인핸드 기준), 무기별 특화:**
  - **검** → 기본 올라운더 + 공격력 소폭 보너스
  - **창** → 긴 리치 + 관통
  - **한손 둔기** → 약한 기절 (큰 망치의 라이트 버전)
  - **한손 도끼** → 방어력 무시율 (적 방어를 일정 비율 관통, 단단한 적에 강함)
  - **소형 방패(오프핸드)** → 방어 역할 (요구·효과 추후)
- **인내 몰빵 → 반격형 탱커 가지 (패링 스택형)**: 정확한 타이밍 막기=패링 성공 → 무피해 + **반격 스택 +1**, **랜스·건랜스 평타가 스택을 소모**해 강화된 타격. "정확히 막을수록 되돌려줄 한 방이 커진다." 패링의 실력 손맛 + 스택의 누적 쾌감. 솔로에도 손맛 좋음. **무기(메인=찌르기 무기 + 오프핸드=방패), 특징:**
  - **랜스** → 긴 리치(+관통). 평타에 반격 스택 1개 소모.
  - **건랜스** → 평소 찌르기(스택 소모 없음) + **홀드 시 좌클릭 = 포격(폭발 사격) → 반격 스택 전부 소모**. 쌓았다 한 번에 터뜨리는 스타일.
  - **대형 방패** → 왼손(오프핸드) 방패, 방어 담당 (무기 특징 X).
- 무기(예정): 검(균형) · 도끼(위력) · 둔기(충격).

**민첩 (도적/궁수)** *(구상 중)* — 하위 스탯(신속/숙련) 투자로 가지가 갈림. **공유 무기: 단검** (세 갈래 공통, 요구=신속+숙련 합 24, 특징=이동속도 보너스):
- **신속 몰빵 → 극한의 암살자 가지**: *이동기 자체가 공격*. **돌진 관통**(적을 꿰뚫으며 벰) + **순간이동(블링크)**(기습·이탈)을 함께 운용. 콤보: 순간이동 기습 → 돌진 관통 → 순간이동 이탈. 속도=공격이자 회피, 미끄러지듯 누비며 벰. **무기: 단검(공유, 이동속도 보너스, 짧은 리치) · 쿠나이(백어택 데미지 보너스, 짧은 리치; 요구=신속 단일).**
  - 참고: "기동 카이팅 궁수" 안도 나왔으나 신속=극한 암살자로 결정. **도적은 근접 중심 — 원거리/궁수는 접음**(추후 필요하면 재검토).
- **신속+숙련 → 정통 로그 가지**: 기동성+공격속도 균형. 기믹 없이 치고 빠지며 꾸준히 싸우는 만능 스키미셔. 입문·만능(전사의 "보편 전사"에 대응). **무기: 레이피어(긴 리치 찌르기 — 단검보다 한 발 멀리) · 단검(공유).** (도적은 근접 중심 — 원거리/궁수는 접음. 무기 공유 원칙: 단검을 암살자·정통 로그 공용, 갈래는 스탯 빌드로 구분.)
- **숙련 몰빵 → 콤보형 가지**: 적에게 붙어 빠른 쌍검 연타로 **콤보 카운터 누적**(끊기면 리셋) → 마지막에 누적 콤보를 **마무리기로 폭발**(콤보 수 비례). "쌓아 터뜨린다." **무기: 쌍검**.
  - **쌍검** — 양손 빠른 연타로 콤보 누적. 숙련 특화.

**마법사 (지능)** *(구상 중)* — 하위 스탯(마력/제압) 투자로 가지가 갈림. 마나는 자원(전체 지능 비례):
- **마력 몰빵 → 폭발 누커 (영창형) 가지**: *느린 영창 + 강한 한 방*. 고위험(영창 중 무방비·느림)·고보상(압도적 단일 화력). 전사 차징형의 마법 버전. 영창 안정성·위치 선정·엄호가 묘미. **무기: 큰 지팡이(대형 스태프) → 특징: 마나 소모량 비례 마법 데미지 증가**(마나 많이 쓰는 큰 마법일수록 위력↑).
- **마력+제압 → 보편 마법사 가지**: 화력+제압 균형, 두루 쓰는 정통 캐스터(보편 전사·정통 로그에 대응). **무기: 완드(단독) → 특징: 마나 소모량 감소**(효율적으로 자주 시전). (큰 지팡이와 정반대 결.)
- **제압 몰빵 → 컨트롤러 (지속·소모전형) 가지**: 적에게 디버프·저주·도트를 겹겹이 깔아 *말려죽이고*, 자신·아군엔 버프를 둘둘 둘러 버팀. 효과 지속시간↑로 한번 건 게 오래감. 장기전·보스에 강, 순간 폭딜 약. (누커의 정반대.) **무기: 마도서(그리모어) → 특징: 디버프·버프 지속시간 증가**(건 효과가 더 오래감).

**하이브리드 줄기 (공개 — 교차 스탯 투자로 열림)** *(구상 중)*

**트리 구조 = 삼각 방사형.** 가운데(시작점)에서 STR·DEX·INT 세 갈래로 뻗음. *순수 빌드 = 한 꼭짓점 끝*, *하이브리드 = 두 꼭짓점 사이(변)에 걸침*. 하이브리드는 **공개**(히든 아님).
```
        STR
      /      \
[마검사]    [궁수]
공격+마력   공격+신속
  |            |
 INT ──────── DEX
      [DEX↔INT]
```
- **힘↔민첩 = 궁수 (공격+신속)**: 강한 화살(공격=물리 위력) + 카이팅(신속=기동). "강하게 쏘고 빠르게 빠진다." 무기: **활 · 석궁** (도적에서 뺀 원거리가 여기 정착). ✅
  - **활** → ① **무빙샷**(당기는 동안 이동 둔화 제거 → 전속력 카이팅 사격) ② **오버차지**(만충 이후 더 당기면 데미지 추가).
  - **석궁** → ① **적중 시 장전 속도 증가** ② **방어 무시율**.
- **힘↔지능 = 마검사 (공격+마력)**: 검으로 베며 마법을 두름, 물리·마법을 엮음. 무기: **마검(마력 깃든 검) / 검 + 마도서(오프핸드).** ✅
  - **마검** → **평타에 마법 데미지 추가**(물리타에 마법 피해 얹힘 — 공격+마력 융합).
  - **검 + 마도서** → 추후 (일단 마검의 평타+마법 융합이 마검사 핵심).
- **민첩↔지능 = (가칭) 주술 검객/저주 도적 — 숙련+제압**: 빠른 공격(숙련)에 디버프·상태이상을 실어 순식간에 중첩, "빠른 손으로 말려죽이는" 템포 디버퍼(컨트롤러의 근접·속공 버전). 무기: **사슬낫(쿠사리가마)** — 베며 옭아맴. **특징: 적중 시 독·출혈 도트 중첩**(빠른 공격으로 DoT 순식간에 누적). 이름 추후.

**마수 / 침식 (특수 레이어 + 세계관)** *(구상 중)* — 기본 클래스가 아님. 침식이 세계관으로 상승해 일정 수준이 되면 3개 기본 클래스 위에 마수화(변신)가 열리는 *별도 레이어*. 변신 메커니즘(§2.4)은 유지.

**세계관 (침식):**
- **배경 = 평범한 세계에 막 닥친 재앙.** 멀쩡하던 세계(바닐라 같은)에 침식이 **갑자기 나타나** 번지기 시작 (기원 불명 — 미스터리 자체가 분위기, 추후 코어에서 실마리 줄지 미정). 아직 막을 희망 있음.
- **시작 지점 = 동굴 속, 거대한 갈라진 거석 앞에서 플레이어가 깨어남.** 플레이어 정체는 굳이 정하지 않음(기원 불명 침식과 짝 — 그냥 "너"가 거기서 눈을 뜨며 시작).
- **침식의 코어** = 세계 한 구석에 있는 감염의 근원. **모드의 최종 목표 = 코어 파괴(정화).**
- 코어를 중심으로 **침식이 바깥으로 점점 확산** → 동적인 "살아있는 세계"(코어 근처=깊은 오염 위험지대=고레벨, 가만두면 세계가 잠식됨). 플레이어는 오염지대를 뚫고 코어로 향함.
- **오염 지역 엔티티 = 침식 변이체.** ① 침식된 바닐라 몹(좀비→침식 좀비 등, 더 흉포·강함) ② 완전히 새로운 마수. **오염이 짙을수록 변이·난이도↑**(외곽=살짝 변이, 코어 근처=형체도 알아보기 힘든 흉악한 마수). → 코어로 갈수록 험해지는 난이도 곡선. **플레이어 마수화도 같은 침식** → "괴물을 사냥하다 스스로 괴물이 되어간다"(테마 일치).
- **코어 조각(침식 조각)의 용도 = 플레이어 선택** (핵심 갈림길):
  - **침식 능력치 해금** → 침식↑ + 마수화 강화(대가 동반).
  - **스킬 포인트로 사용** → 스킬 습득(§2.8).
  - → "괴물의 힘이냐 인간의 힘이냐". 안 삼키고 스킬에만 쓰면 순수 인간, 침식에 쏟으면 괴물이 되어감 → "선택한 자의 길".
- **코어 조각 출처 = 침식 계열 보스 처치 드롭.** → 보스가 핵심 콘텐츠 축(침식 조각 + 리스펙 아이템 둘 다 보스 보상). 오염지대 곳곳에 침식 보스(관문)들, 코어로 향함. (최종 보스 = *코어 자체* vs *코어를 지키는 수호 보스* — 미정, 추후 구상.)

### 2.6 무기 / 장비

- **필요 스탯 보유** (스탯이 클래스·무기·전투수치를 여는 공통 열쇠). **요구는 하위 스탯**(1차 아님).
- **요구치 원칙:**
  - **공유/기본 무기** = 그 클래스 두 하위 스탯 **합 24** 요구 → 어떤 빌드든 8레벨이면 사용 (예: 도적 단검=신속+숙련 합24, 전사 검=공격+인내 합24, 마법사 기본=마력+제압 합24).
  - **몰빵 특화 무기** = 단일 하위 스탯 요구 (예: 차징 무기 = 공격 24).
  - 하이브리드 무기 = 두 *서로 다른 우산*의 하위 스탯 요구 (예: 마검=공격+마력, 사슬낫=숙련+제압, 활=공격+신속).
  - 스케일 기준: 레벨당 3p → 8레벨=24p, 10레벨=30p.
- 미달 시 = **사용은 가능하나 페널티 (소프트)**. 페널티 형태는 추후 밸런싱.
- **클래스 연계**: 클래스마다 어울리는 무기 *종류*가 있고, 그 무기를 들어야 스킬 사용 가능(§2.7).
- **장비 = 2차 스탯 옵션 제공자.** 장비가 2차 스탯 옵션을 달고 나옴 (첫 항목: **쿨감**. 향후 치명타·저항 등). 데이터팩으로 장비별 옵션 정의.
  - → "2차 스탯/장비 옵션 층"(공격력·체력·속도 같은 1차 파생 + 쿨감·치명·저항 등 장비 옵션)이 1차 능력치·장비·스킬·(추후)몹이 공유하는 계기판.

### 2.9 무력화(스태거) 시스템

- **모든 공격에 "무력화 수치", 모든 몬스터에 "무력화 게이지".** 공격으로 게이지를 깎음.
- 게이지를 **다 깎으면 → 딜타임 발동 = 적 "행동 불능"** (피해 증폭은 없음, 안전하게 몰아칠 시간).
- **게이지 회복 없음** (깎은 만큼 누적 보존 → 길게 싸워도 진행도 유지). 단 **무력화 발동 시 게이지 초기화** (다음 무력화는 처음부터 다시 깎아야).
- **무기 연계:** 둔기류(큰 망치·한손 둔기) = 무력화 수치 높음(빨리 무너뜨림), 빠른 무기(단검·콤보) = 한 방당 낮지만 빠르게 누적. → 기존 "기절·넉백" 같은 흩어진 효과를 *무력화 시스템 하나로 통합*.
- (미정) 무력화 수치가 특정 스탯과 연동될지, 딜타임 길이, 보스의 큰 게이지 등 — 추후.

### 2.12 가드(방패 막기) 시스템 변경

- **바닐라 방패 = 정면 피해 100% 차단** → **비율 경감으로 변경.**
- 경감 비율은 **방패 종류마다 다름** (고정값 X). 구체 수치는 방패별로 추후.
- 폭발 등 예외 처리, 스탯(인내 등) 연동 여부는 추후.

### 2.13 마을 (정착지)

- **정착지 = 두 카테고리:**
  - **국가(도시국가)** — 6세력 = 6개 도시국가. 각 세력당 **중심 도시 1개**가 국가 그 자체. 단계 구분 없음. 왕·귀족 등 정치 구조 존재. 세부는 §2.14.
  - **마을** — *전부 무소속*. 세력에 속하지 않은 변경의 정착지. **도시는 없음**(도시는 국가에만).
- **마을 = 거점형** — 휴식·재정비 거점. 핵심 시설 3종: **여관 · 상점 · 대장간**.
- **마을 크기 (3단계):**

  | 단계 | 시설 | 규모 | NPC |
  |---|---|---|---|
  | **야영지** | 모닥불·천막 | 임시 거점, 휴식만 | 일반 주민 1~2명 |
  | **작은 마을** | 여관 | 농가 몇 채 | 촌장 + 여관주 + 일반 주민 몇 |
  | **큰 마을** | 여관·상점·대장간 | 표준 마을, 풀세트 | 촌장 + 여관주 + 상인 + 대장장이 + 일반 주민 다수 |

- **외형 다양화 — 변형 풀:** 각 시설(여관·상점·대장간·야영지)마다 여러 디자인 변형 보유. 마을 생성 시 풀에서 무작위 선택 → 마을마다 외형 달라짐(같은 여관이 반복되지 않음).
- **구조물 간 최소 거리:** 마을·보스 구조물·다른 마을은 서로 일정 거리 떨어져 스폰. 구체 거리 추후.
- **스폰 빈도 (단계별 차등, 잠정):**

  | 단계 | 평균 간격 | 체감 |
  |---|---|---|
  | 야영지 | 200~400블록마다 | 자주 마주침 |
  | 작은 마을 | 500~800블록마다 | 가끔 |
  | 큰 마을 | 1000~1500블록마다 | 여행 중 발견 |

  - 도시는 마을 카테고리에서 빠짐(국가 거점). 국가 거점 스폰 규칙은 추후.
  - 보스 구조물 배치(추후 설계)와 함께 분포 재조정 필요. 보스 구조물·마을·국가 거점이 서로 너무 가까이/멀리 안 붙도록 통합 규칙 만들어야 함.
- **침식 진행도에 따른 마을 상태 (3단계):**

  | 상태 | 설명 | 플레이어 경험 |
  |---|---|---|
  | **평화 마을** | 침식 거리 멂. 정상 운영 | 휴식·거래 |
  | **피난 마을** | 침식 접근. 주민 떠나 빈 시설만 남음. 적대 종족(고블린·놀·가고일·유령·미믹 등 §2.10)이 점거 가능 | 약탈·탐색·전투 |
  | **침식 마을** | 주민이 침식 변이체로 변함 | 전투 |

- 추후: 마을 위치/스폰 규칙(바이옴 기반·침식 거리 기반 등), 거래 가격, 마을별 특색, 바이옴별 외형 테마.

### 2.14 국가 (도시국가) — 진행 중

- **6세력 = 6개 도시국가.** 각 세력당 **중심 도시 1개**가 국가 그 자체. 단계·하위 도시 없음.
- 영토 = 중심 도시 + 주변 영역(농경지·산·숲·바다 등 세력 특성 따라).
- **세력별 도시 외관:**

  | 세력 | 도시 외관 |
  |---|---|
  | **Humapax** | 대평원 위 거대 성벽 도시. 대성당 중심, 농경지에 둘러싸임 |
  | **ArVis** | 산맥 깎아 만든 요새형 도시. 굴뚝·기계 장치 |
  | **InvestLux** | 마법 결정으로 둘러싸인 학원 도시 (중립 위치) |
  | **Animmort** | 거대한 숲 안, 나무 위·뿌리 사이 엘프 도시. 세계수 중심 |
  | **Subilio** | 산 내부 지하 도시. 거대 동굴, 대광산 입구 |
  | **Poqua** | 해상 도시. 산호·진주·수정으로 만든 우아한 건축 |
- **정치 구조 — 세력별 차별화** (게임 시스템 연계는 가벼움, 외관·NPC 톤 차별점 용도):

  | 세력 | 정치 형태 |
  |---|---|
  | **Humapax** | 왕 + 교황 (왕정·종교 이중 권력) |
  | **ArVis** | 장인 평의회 (왕 없음, 기술자 회의제) |
  | **InvestLux** | 현자 회의 (학자 평의회) |
  | **Animmort** | 엘프 여왕 (불멸 통치) |
  | **Subilio** | 드워프 왕 + 장로단 |
  | **Poqua** | 해양 여왕 |
- 세력 6개: Humapax · ArVis · InvestLux · Animmort · Subilio · Poqua (§2.10).
- **도시국가 공통 시설:**

  | 시설 | 역할 |
  |---|---|
  | **왕궁** | 왕 거주, 정치 중심, 메인 퀘스트 |
  | **여관·상점·대장간** | 마을 기본 시설(확장 가능) |
  | **시장** | 전문 상점 풀세트 |
  | **병영** | 경비병·군사 NPC |
  | **광장** | 공공 공간·게시판(의뢰)·만남 |
  | **길드홀** | 모험가 길드 / 퀘스트 허브 |
  | **도서관** | 정보·책 |
  | **감옥** | 죄수·범죄 시스템(추후) |
  | **성벽** | 도시 방어 (시각적 + 게이트) |

  - 신전 = 공통에서 제외(세력별 특수 시설 후보).

- **세력별 특수 시설 (진행 중):** 게임 기능이 있는 건물만. 농장·훈련소 같은 외관·분위기 요소는 제외.

  - **Humapax — 대성당** (국교 본부, 대인구를 하나로 묶는 정신적 구심점. "평화" 명분의 받침대):
    - 침식 정화 의식 (디버프 해제 / 마수화 일시 봉인 등 — 세부 추후)
    - 종교 퀘스트 허브 (사제 NPC 의뢰)
    - 신앙/축복 버프 (기여 시 버프 부여)
    - **히든 클래스 거점** (성기사·신관 계열 — 세부 추후)

  - **ArVis — 대공방** (기술의 본거지. "기술력 = 군사력" 정체성):
    - 여기서만 다룰 수 있는 **독점 강화·제작 장비** (마을 대장간 상위)
    - 기술 의뢰 (장인 NPC)
    - **히든 클래스 거점** (장인·발명가·총사 계열 — 세부 추후)

  - **InvestLux — 마법 대학원** (마법 연구 집단, 침식 집중 연구):
    - 여기서만 배울 수 있는 마법 스킬·책
    - 침식 연구 정보 (메인 스토리 단서·침식 분석)
    - 마법 의뢰 (연구원 NPC)
    - **히든 클래스 거점** (대마법사·침식술사 계열 — 세부 추후)

  - **Animmort — 세계수** (자연·생명의 거점, 침식 감시):
    - 자연 회복 (체력·마나 완전 회복 / 명상 버프)
    - 자연 마법 학습 (드루이드·레인저 계열 스킬)
    - 침식 감지·경계 정보 (Animmort 정체성 살림)
    - 숲 의뢰 (엘프 NPC)
    - **히든 클래스 거점** (드루이드·레인저·자연술사 계열 — 세부 추후)

  - **Subilio — 대광산** (드워프 광산도시. 깊이 들어갈수록 위험·신비. 자원 시설이자 던전):
    - 희귀 광물 채굴·자원 거래
    - 광부 의뢰 (드워프 NPC)
    - 대광산 던전 — 미답 영역, 깊이 단계별 강함
    - **고대 문명 / 고대 골렘 / 고대 유물** (대광산 최심부, 아무도 들어가본 적 없는 곳. §2.10 고대 골렘=고대 문명 복선과 연결)
    - **히든 클래스 거점** (드워프 전사·룬 술사·고대 발굴자 계열 — 세부 추후)

  - **Poqua — 해양 신전** (우아한 해양 종족의 신전. 바다 변화 통해 침식 간접 감지):
    - 해양 의식 (수중 호흡·수영 가속 버프)
    - 해양 마법 학습 (물 마법·치유 계열)
    - 해양 침식 정보 (바다 생물 변화 통한 간접 감지 — Poqua 정체성)
    - 해양 의뢰 (사제 NPC)
    - **히든 클래스 거점** (해양 사제·물 마법사 계열 — 세부 추후)

- **플레이어 관계:**
  - **입장 = 자유.** 누구나 도시국가 출입 가능. 평판이 입장을 막진 않음.
  - **국가별 평판 시스템.** 6개 국가 각각 평판 점수.
  - **평판 6단계** (음수 2 / 양수 3 비대칭 — 음수는 단순 적대, 양수는 보상 세분화):

    | 점수 | 단계 | 의미 |
    |---|---|---|
    | **-2** | 적대 | NPC·경비병 공격 |
    | **-1** | 경계 | 가격↑, 일부 거래 거부 |
    | **0** | 중립 | 기본 시작값, 평범한 대우 |
    | **1** | 우호 | 가격↓, 사이드 퀘스트 열림 |
    | **2** | 신뢰 | 특수 상품 해금, 메인 퀘스트 |
    | **3** | 영웅 | 특수 혜택, 그 국가 한정 보상 |

  - 평판 변동 요인(추후): NPC 공격·도둑질·퀘스트 보상·세력 외교(§2.10 세력 간 관계: Humapax↔ArVis 전쟁, Animmort↔Subilio 적대, Animmort↔InvestLux 협력, Subilio↔ArVis 우호, Poqua↔Humapax 긴밀)에 따른 연동 등.
  - 회복 수단·구체 수치 추후.

- **세력 바이옴 (커스텀, 월드당 1개씩):** 각 도시국가는 자기 전용 커스텀 바이옴 안에 자리잡음. **세계에 단 6개**(반복 스폰 없음 — 표준 바이옴과 다른 특수 처리 필요).

  | 세력 | 커스텀 바이옴 | 결 |
  |---|---|---|
  | **Humapax** | 황금 들녘 | 밝은 노란 평원, 거대 농경지, 풍요·평화 |
  | **ArVis** | 강철 산맥 | 검은 산맥, 굴뚝 연기, 기계 구조물 산재 |
  | **InvestLux** | 마력 평원 | 보랏빛 마력 결정이 흩어져 빛나는 평원 |
  | **Animmort** | 영원수림 | 거대 나무 우거진 숲, 빛나는 꽃·이끼 |
  | **Subilio** | 심연 산악 | 거대 산 + 동굴 입구 산재 (지하 입구) |
  | **Poqua** | 수정 해역 | 산호·진주·수정 빛나는 바다 |

- **6세력 바이옴 월드 배치 (위치 확정, 정확한 좌표는 추후):**
  - 플레이어 스폰 = **원점 (0, 0)** = §2.10 시작 지점(동굴 거석). **중앙은 빈 영역**, 6세력은 모두 외곽 분포.
  - 배치 원칙: §2.10 세력 관계가 지리에 반영 (우호 인접, 적대도 인접 시 국경 분쟁 자연스러움).
  - **확정 위치:**

    | 위치 | 세력 |
    |---|---|
    | 좌상단 | **Subilio** (심연 산악) |
    | 상단 중앙 | **ArVis** (강철 산맥) |
    | 우상단 | **Humapax** (황금 들녘) |
    | 좌측 중상단 | **InvestLux** (마력 평원) |
    | 좌하단 | **Animmort** (영원수림) |
    | 우하단 | **Poqua** (수정 해역, 거대 바다) |

  - 지리적 특징:
    - **상단 산맥 라인**: Subilio(좌상단) → ArVis(상단 중앙)로 이어지는 산맥 줄기. Subilio↔ArVis 우호 반영.
    - **우상단 인접**: ArVis ↔ Humapax — 100년 전쟁의 국경 분쟁 자연스러움.
    - **좌측 세로 라인**: Subilio → InvestLux → Animmort (위→아래). InvestLux↔Animmort 협력 반영.
    - **우측 세로 라인**: Humapax → Poqua (위→아래). 긴밀 교류 반영.
    - Animmort ↔ Subilio 적대는 대각선 끝(좌하 vs 좌상)으로 분리.
- **침식 코어 = 하단부 시작 → 위쪽으로 확산** (월드 -Z 방향에서 +Z 방향으로 진행). §2.10 각 세력의 침식 인지도와 정확히 일치:
  - Animmort(좌하단)·Poqua(우하단) = 가장 가까움 → 감시·간접 감지
  - InvestLux(좌측 중상단) = 중간 → 집중 연구
  - Subilio(좌상단·지하)·Humapax/ArVis(상단) = 가장 멀음 → 미인지·무관심
  - §2.13 마을 상태(평화/피난/침식) 분포도 자연스럽게 결정 — 하단 마을이 먼저 피난·침식 단계로.
- 추후: 정확한 좌표·거리·면적, 평판 시스템 세부.

## 3. 첫 구현 슬라이스 (스탯 코어 최소 수직 슬라이스)

> 하이브리드 배선 전체를 한 번 관통하는 최소 루프. 나머지는 데이터/모듈로 확장.

1. 데이터팩이 1차 능력치 1개 정의 (예: 힘)
2. 플레이어가 그 값을 보유 (Data Attachment, 영속·재접속 유지)
3. 데이터팩이 파생 규칙 1개 정의 (예: 힘 1당 공격력 +0.5)
4. 값을 바꾸면 실제 공격력 변화 (임시 명령어 `/ark stat set|get`)
5. 클라이언트 동기화 + 최소 확인 수단

**이번 슬라이스에서 제외**: 레벨·포인트 투자, GUI, 커스텀 Attribute 풀, 몹 적용.

### 모듈 경계(안)

`stat`(레코드+Codec) · `registry`(데이터팩 레지스트리) · `player`(Attachment 저장) · `engine`(재계산·적용, 단위 테스트 대상) · `net`(동기화) · `command`(개발용)

### ✅ 구현 결과 (2026-06-04 검증 완료)

NeoForge 1.21.1 + MC 1.21.1 + NeoForge 21.1.176 환경. 메모대로 모듈 6개 작성.
스킵: `net` 동기화는 GUI 없으니 다음 슬라이스로(서버 단독 처리).

검증된 동작 (`runClient` 인게임, 단일 플레이어 크리에이티브):
- 모드 내장 데이터팩 (`data/ark/ark/primary_stat/strength.json`, `derived_rule/strength_attack.json`) 자동 로드.
- `/ark stat get` → 등록된 능력치 표시.
- `/ark stat set ark:strength 50` → `setStat()` → `recompute()` → `minecraft:generic.attack_damage`에 안정 ID(`ark:derived/ark__strength_attack`)로 모디파이어 적용.
- `/attribute @s minecraft:generic.attack_damage get` 결과 1.0 → 26.0 (= 1.0 + 50×0.5) 확인 ✅
- `/kill` 후 리스폰 → 값·모디파이어 유지 (`copyOnDeath()`) ✅
- 월드 재진입 → NBT 복원 → 값·모디파이어 유지 ✅

### 🪲 구현 중 발견한 마찰점

1. **MC 1.21.1의 vanilla Attribute id는 옛 `minecraft:generic.*` 형식.**
   1.21.2부터 `generic.` prefix가 빠지지만 1.21.1은 옛 형식이라 데이터팩 target에 `minecraft:generic.attack_damage`라고 적어야 함. *데이터팩 작성 가이드/검증기에 반영 필요.* (남은 과제)
2. **`runClient`는 `build/resources/main/`을 봄.** `src/main/resources/` 수정만으론 반영 안 됨 → `./gradlew processResources` 후 인게임 `/reload` 또는 월드 재진입 필요. 개발 흐름 메모: *데이터팩 JSON 변경 후 processResources 잊지 말 것.*
3. ~~**모드의 데이터팩 레지스트리는 `/reload`로 갱신되지 않음.**~~ ✅ **해결 (2026-06-04 다듬기 슬라이스):**
   `OnDatapackSyncEvent` 핸들러 추가 — 로그인 시·`/reload` 시 자동으로 `ensureDefaultsAndRecompute()` 호출. (단 레지스트리 *콘텐츠* 자체는 여전히 월드 시작 시 고정이라, JSON 변경분 반영은 월드 재진입 필요.)
4. ~~**신규 플레이어는 `default_value` 자동 미적용.**~~ ✅ **해결 (2026-06-04 다듬기 슬라이스):**
   `StatEngine.ensureDefaultsAndRecompute()` 추가 — 데이터팩에 있는데 PlayerStats에 없는 능력치를 default_value로 채움. `OnDatapackSyncEvent`(로그인 포함) 시점에 호출.

### ✅ 레벨업 슬라이스 (2026-06-04 검증 완료)

**구현:**
- `PlayerStats` 확장 — `highestLevel`, `pointsUsed` (Codec record style, 마이그레이션 비호환). `POINTS_PER_LEVEL = 3`.
- `PlayerXpEvent.LevelChange` 핸들러 — 자연 획득·`/xp add` 잡음.
- `PlayerTickEvent.Post`로 20틱(1초)마다 폴링 — `/xp set`처럼 *이벤트 없이* 필드 직접 설정하는 경로 보완.
- 명령어 `/ark stat invest <stat> <amount>` — 한도 검사(`pointsRemaining`, `def.max()`) 후 분배·recompute.
- 명령어 `/ark stat get` — 레벨·적립/남은 포인트·능력치 목록 표시.
- 사망 시 XP 보존 — `LivingExperienceDropEvent` 캔슬(플레이어 한정) + `PlayerEvent.Clone`에서 `experienceLevel/Progress/totalExperience` 복원.
- `ensureDefaultsAndRecompute()`에 `updateHighestLevel(player.experienceLevel)` 추가 — 모드 추가된 기존 월드 첫 진입 시 반영.

**검증 결과:**
- `/xp set @s 10 levels` 1초 후 `[ARK] ... highest lv 10, points 0/30 (remaining: 30)` ✅
- `/ark stat invest ark:strength 20` → `+20 → 25 (remaining: 10)` + `attack_damage 13.5` ✅
- `/xp set @s 5 levels` → `/kill` → 리스폰 → `xp query` **5 유지**, `highest lv 10` 유지, invest 20 유지 ✅
- `/xp set @s 3 levels` → `highest lv 10` 그대로 (단조 증가) ✅

**디자인 결정 (§2.2 갱신):** 레벨업 페이싱은 *메인 퀘스트 라인이 페이서*. 따라서 "레벨당 3pt" 비율 그대로, 바닐라 XP 획득량도 그대로 (퀘스트 + 진행 중 잡몹·채집으로 자연스러운 속도). 정밀 밸런스는 메인 퀘스트 시스템 추가 시점에 검증.

### ✅ 4 바닐라 매핑 스탯 추가 (2026-06-04, 코드 무수정)

## 2.10 세력 (World Factions)

### 인간 세력 (3개)
침식이 닥친 상황에서도 Humapax·ArVis는 100년 전 사소한 갈등에서 시작된 적대를 이유도 없이 이어가는 중. InvestLux만 침식에 집중.

| 이름 | 기반 | 군력 | 침식 태도 |
|---|---|---|---|
| **Humapax** | 넓은 평지·풍부한 농업·대인구 | 냉병기 중심 물량전 | 무관심 (전쟁 중) |
| **ArVis** | 거친 산맥·풍부한 자원·기술력 | 소수정예·기술 기반 | 무관심 (전쟁 중) |
| **InvestLux** | 마법 연구자 집단 | — | **침식 집중 연구**, 중립 |

- Humapax = Humanus(인간) + Pax(평화). "인간의 평화"를 표방하나 정작 전쟁 중.
- ArVis = Ars(기술) + Vis(힘). 기술력이 곧 군사력.
- InvestLux = Investigatio(탐구) + Lux(빛·지식). 침식의 실마리를 쫓는 집단.

- 마수화 = 발동 토글, 허기 유지, 사냥 회복, 침식 스케일
- 클래스 = 명시적(Model A), **기본 3개(전사·도적/궁수·마법사)**, 가지치기 트리(하위 스탯으로 분기, 각 3갈래=9빌드), 스탯 문턱 해금, 택1, 변경은 리스펙, 클래스→무기→스킬
- 마수/침식 = 4번째 클래스 아님. 침식(세계관으로 상승)이 일정 수준이면 3클래스 위에 마수화 레이어 개방(추후 설계).
- 히든 클래스 = 비밀 조건 발동(영구 해금)+스탯 요구치, 발동 시 전환 택1
- 스킬 획득 = 3계층(클래스 트리 / 책 숨겨진 스킬 / 히든 클래스 스킬), 데이터팩 정의·마나 소모
- 무기 = 필요 스탯(하위 스탯 요구), 소프트 페널티. 차징 무기=공격 24. Sentinel 무기=랜스·건랜스(메인)+대형 방패(오프핸드). 양손 방패 제거.
- 클래스 선택 = 10레벨, 해금 최소 문턱 ≈ 한 스탯 20(8레벨 도달 가능). 레벨당 3p, 10레벨=30p 스케일 기준.
