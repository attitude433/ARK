# ARK — 게임 디자인 메모

> 마인크래프트 NeoForge 1.21.x RPG 모드
> 작성: 2026-06-01 · 상태: **설계 진행 중 (초기 브레인스토밍)**
> 이 문서는 정식 스펙이 아니라 **결정 사항 기록용 메모**입니다. 계속 늘고 줄어듭니다.

---

## 1. 큰 방향

- 장르: **전투·스킬 중심의 액션 RPG** + **"살아있는 세계"**(유기적으로 반응하는 세계)
- 제작 철학: 욕심내지 않고 **한 단계씩**. 가장 작은 것부터 끝까지 굴린 뒤 위에 얹는다.
- 기술 기반: **NeoForge 1.21.x**, **데이터팩 주도 설계** (모드는 시스템·코덱·엔진을 제공, 콘텐츠는 데이터팩 JSON으로 정의)
- 모드 ID: `ark` (브랜드 표기 "ARK"), 데이터팩 경로 `data/ark/...`

### 분해 & 제작 순서 (의존 사슬)

```
[기반] 전투 & 스킬 코어 (스탯이 출발점)
   └→ [A] 살아있는 생태계
        ├→ [B] 평판/결과
        └→ [C] 시스템 상호작용
             └→ [D] 동적 월드 진행
```

→ **첫 슬라이스 = 스탯 시스템 코어.** 생태계·평판 등은 그 위에 데이터/모듈로 얹는다.

### 아키텍처 방향 (스탯 엔진)

- **하이브리드 접근**: 1차 능력치는 데이터 주도 커스텀, 파생 효과는 가능한 한 바닐라/커스텀 **Attribute 모디파이어**로 적용(바닐라와 자동 연동), 표현 불가한 것만 엔진이 직접 처리.
- 비유: *모드 = 어휘, 데이터팩 = 문장, 필요하면 코드로 어휘 확장.*
- 저장: 플레이어별 **Data Attachment** (NBT 영속화 + 클라 동기화).

## 2. 확정된 설계

### 2.1 1차 능력치 (내적 능력 · 정수값 · 레벨업 포인트로 성장)

| 능력치 | 효과 | 성격 |
|---|---|---|
| **힘 (STR)** | **공격**(→공격력) / **인내**(→체력) | 묵직한 한 방, 단단함 |
| **민첩 (DEX)** | **신속**(→이동속도) / **숙련**(→공격속도) | 빠르게 자주 |
| **지능 (INT)** | **마력**(→마법뎀) / **제압**(→제압 위력·효과 지속시간) | 스킬·마법의 길 |

> **※ 침식(erosion)은 기본 스탯이 아님 — 별도 특수 스탯.** 레벨업 포인트로 올리지 않고 **세계관 관련 방식으로 상승**(추후 설계). 마수화(변신)를 다스리는 힘. 침식/마수는 *3개 기본 클래스 위에 얹히는 특수 레이어*(추후 별도 설계). 변신 안 하면 무능력 등 변신 메커니즘은 §2.4 유지.

> **스탯 세분화(2단 분화):** 클래스 내 차별화를 위해 1차 능력치를 하위 2갈래로 쪼개 *따로 투자*. 1차는 여전히 클래스 뿌리(우산)로 남아 4클래스 구조 유지.
> - **힘** → **공격**(공격력) / **인내**(체력) ✅
> - **민첩** → **신속**(이동 속도) / **숙련**(공격 속도) ✅
> - **지능** → **마력**(마법뎀) / **제압**(제압=군중제어·디버프 위력 + 버프/디버프 효과 지속시간) ✅
>   - **마나는 하위 스탯에서 분리 → "자원"**으로 전체 지능 투자량에 비례(우산). (마나는 "특징"이 아니라 자원이라 하위 스탯에서 뺌.)
> - **침식은 기본 스탯에서 제외** (별도 특수 스탯, 세계관으로 상승 — 위 ※ 참고).
>
> → **포인트 투자 대상 = 하위 스탯 6종**(공격·인내·신속·숙련·마력·제압). 레벨업 포인트 3개를 이들에 분배. 클래스 가지는 어떤 하위 스탯을 얼마나 찍느냐로 갈라짐. (침식은 포인트 투자 대상 아님.)

- 비율·구체 수치는 전부 **추후 밸런싱**.

### 2.2 성장

- 바닐라 경험치 **레벨 +1마다 스탯 포인트 3개** 영구 적립 → **하위 스탯 6종(공격·인내·신속·숙련·마력·제압)에 자유 분배.** (침식은 포인트 투자 대상 아님 — 세계관으로 상승.)
- **경험치·레벨은 영구 유지** (죽음 등으로 손실 없음 — 바닐라 손실 동작을 덮어씀).
- 적립 포인트·분배값은 현재 경험치 레벨과 **분리** 저장. (레벨이 안 깎이므로 받은 포인트 = 레벨 × 3.)
- 포인트 분배용 **전용 화면** 필요 (기능만 확정, 비주얼은 추후).
- **리스펙(재분배) = 가능, 단 특정 아이템 소모.** 아이템 출처 = **퀘스트/보스 보상**.
  - 개발 중엔 명령어/크리에이티브로 아이템 지급해 테스트, 정식 배치는 콘텐츠 단계.

### 2.3 마나

- **모든 빌드가 기본 마나 보유 + 지능이 증폭.** 지능 직업이 마나 의존도가 높음.
- 재생 = **전투 외 빠른 회복** (전투 중엔 거의 안 참 → "전투 한 판의 예산").
- 소모처 = 스킬 (스킬 시스템은 추후). 표시 = 마나 바 (비주얼 추후).
- 메모: 마크엔 "전투 중" 상태가 없으므로 **전투 상태 판정**(최근 N초 내 피해 주고받음 등)을 별도로 정의 필요.

### 2.4 침식 → 마수화 (변신 시스템)

- **발동형 변신**: 전용 키 토글. 외형은 추후.
- 유지 대가 = **허기 소모**. 가만히 있으면 허기가 닳아 풀림. 허기 바닥 시 굶주림 위험.
- **사냥 루프**: 몬스터 처치 시 허기 회복 → 계속 싸우면 변신 유지. ("굶주린 야수가 사냥으로 자신을 먹여 살린다")
- 변신 중 효과 (전부 **침식 수치에 비례**):
  - 공격력 ↑ / 체력 재생 / 처치 시 허기 회복량 / 허기 소모 속도(침식↑일수록 ↓, 오래 버팀)
- 평상시(변신 X) 패시브 없음.
- 진화: 침식이 깊을수록 더 강하고 상위 형태로 (단계형 가미).

### 2.5 클래스 (직업)

- **모델 = 명시적 클래스 (Model A).** 클래스가 정체성. **클래스 → 허용 무기 종류 → 스킬** 순서(무기가 클래스를 정하는 게 아니라, 클래스가 쓸 무기를 정함). ("무기에 따라 달라진다"는 직관은 *클래스 안 무기 종류별 스킬*로 살림.)
- **기본 클래스 = 3개 (뿌리 = 기본 스탯):**

  | 뿌리 스탯 | 기본 클래스 | 무기 결 |
  |---|---|---|
  | 힘 | 전사 | 검·도끼·둔기 |
  | 민첩 | 도적/궁수 | 단검·활 |
  | 지능 | 마법사 | 지팡이·완드 |

  - **마수/침식은 4번째 기본 클래스가 아님.** 침식(세계관으로 상승하는 특수 스탯)이 일정 수준이 되면 *3개 기본 클래스 위에 마수화(변신) 레이어*가 열림 — 별도 설계(추후). (충동/억제 같은 추상 분기는 보류.)

- **가지치기 = 어떤 하위 스탯을 찍느냐로 갈라짐** (클래스 내 차별화). 하이브리드(마검사 등)는 *별도 클래스가 아니라 가지*. 같은 클래스라도 무기 종류·하위 스탯 조합·투자량 문턱·스킬 노드 선택·책으로 다양화.
  - 예) 전사 → 공격 집중(딜러) / 인내 집중(탱커) / +신속·숙련(빠른 검사) / +마력(마검사) / +침식(마수전사)
- **하나만 활성화 가능** (여러 개가 열려도 택1). 변경은 **리스펙(스탯 초기화권)**으로 스탯 재분배 → 다른 문턱 충족 → 다른 클래스 선택. (클래스 변경이 별도 기능이 아니라 스탯 초기화에서 흘러나옴.)
- **클래스 선택 시점 = 10레벨.** 그 전엔 무클래스(포인트 적립). 클래스 해금 **최소 문턱 ≈ 한 스탯 20** (8레벨=24p로 도달 가능, 오투자 1~2회 여유분 포함). 10레벨엔 30p로 여유롭게 충족.
- **두 종류:**
  - **일반 클래스**: **스탯 문턱값으로 공개 해금** (예: 침식 N↑ → 마수 클래스 → 마수화 개방, 지능 N↑ → 마법사 계열, 힘 N↑ → 전사 계열).
  - **히든 클래스**: **비밀 조건으로 발동** (특수 스탯 조합 / 비밀 행적 / 숨겨진 퀘스트·유물 / 테마 연계 등 — 구체 트리거는 추후). 발동 시 기존 클래스 유지 vs 히든 전환 중 **택1**.
    - **한번 발동 = 영구 해금** (비밀은 다시 안 채워도 됨).
    - 단 실제 선택·사용엔 **해당 클래스 스탯 요구치 충족 필요** → 이중 관문.

### 2.7 스킬 시스템

- 스킬은 **데이터팩으로 정의** (JSON), **마나 소모** 시전, 지능이 마법 데미지를 키움. 모든 빌드가 조금씩 쓰되 지능 직업이 주력.
- **획득 3계층:**
  1. **클래스 스킬 (공개)** — 일반 클래스 트리를 타며 얻는 기본·주력 스킬.
  2. **숨겨진 스킬 (책)** — 스킬북/스크롤로만 배우는 희귀 스킬 (클래스 무관하게 수집).
  3. **히든 클래스 스킬** — 히든 클래스 발동 시 얻는 고유 스킬.
- **사용 조건 = 클래스에 맞는 무기를 들고 있어야 함.** 무기를 든 순간이 곧 "전투 태세" → 그때만 스킬 키 활성. 무기를 집어넣으면 평소 마크 조작 그대로. (→ 키 충돌·쉬프트 마찰을 자연스럽게 해소.) 클래스마다 어울리는 무기 *종류*가 있음(전사=검·도끼, 마법사=지팡이 등) — 무기 시스템에 "클래스 연계"가 추가됨.
- **입력 매핑 (즉발 스킬 5개):**

  | 입력 | 역할 |
  |---|---|
  | 좌클릭 | 평타 (마나 X, 기본 공격) |
  | 우클릭 | 1번 스킬 |
  | 쉬프트+좌클릭 | 2번 스킬 |
  | 쉬프트+우클릭 | 3번 스킬 |
  | R | 4번 스킬 |
  | C | 5번 스킬 |

- **라디얼 휠 (나머지 스킬): Alt 꾹 누르기** → 원을 가용 스킬 수만큼 파이로 분할, 마우스 드래그로 방향 선택, 원 바깥 삼각형으로 현재 가리키는 슬라이스 표시, Alt 떼면 **그 스킬 즉시 시전** (Alt 꾹 → 방향 → 떼면 발사).
- **로드아웃**: 즉발 5칸 = 빠르게 쓸 스킬(빌드 선택), 휠 = 나머지 전부. (즉발 칸에 어떤 스킬을 올릴지 선택 가능 — 추정)
- **키 매핑 원칙**: 기본값은 *누구나 가진 입력*만 사용(키보드+좌/우클릭). 마우스 옆버튼 등은 기본 제외하되, **모든 스킬 키 재설정 가능**(바닐라 조작 설정 메뉴 등록). F(오프핸드)·T(채팅)·Q(버리기)·E(인벤)는 기본값에서 회피.
- **쿨다운**: 스킬은 **마나 소모 + 쿨다운** 둘 다. 쿨다운은 스킬별로 다름(데이터팩 정의). **쿨다운 감소(쿨감)** 수단 있음 — **다양한 장비의 옵션**으로 확보.
- **스케일 구분**: 스킬 위력 = **스탯별 가중치 합** = 공격력 × a + 마법력 × b. a만 = 순수 공격력 스킬(물리·무술, 힘 빌드 주력), b만 = 순수 마법력 스킬(지능 빌드 주력), 둘 다 = **하이브리드**(마검사 등). 데이터팩에서 스킬별로 a·b 정의. 둘 다 마나+쿨다운 공통.
  - **마수/침식 스킬 = 공격력 기반.** 침식이 변신 중 공격력을 올려주므로 간접 반영됨 → 별도 침식 스케일 불필요, 스케일 축은 공격력·마법력 둘로 단순 유지.
- **스킬 효과 종류 (목표: 전부 지원):** 공격형 · 이동기 · 버프형 · 디버프형 · 회복형 · 소환형 · 설치/장판형.
  - 효과는 **배타적 분류가 아니라 조합 가능한 "부품"** — 한 스킬이 여러 효과를 가짐 (예: "돌진 베기" = 이동기+공격형). 데이터팩이 부품을 조합해 스킬 정의.
  - 설계는 전부 담되 **구현은 점진적**(공격형부터 → 확장). 엔진이 모르는 새 효과는 코드로 어휘 추가.

- **데이터팩 vs 모드 분담:** *스탯·클래스·전투수학·변신 등 고정 핵심 = 모드(코드)*. *스킬 = 데이터팩(JSON)* — 모드가 효과 부품(어휘)을 코드로 제공, 스킬 하나하나는 부품을 조합한 JSON. (스탯은 6종 고정이라 데이터팩화 불필요 → 코드.)
- **스킬 엔진 = 4축 구조** (구상 중):
  1. **부품(효과)** — 즉시/광역/투사체/관통/도트 · 돌진/순간이동/도약/끌당김/넉백 · 버프/디버프/방어막/회복 · 기절/속박/둔화/침묵 · 소환/장판/함정 …
  2. **트리거(연결)** — 한 부품의 결과가 다음을 발동 (명중 시 / 처치 시 / 종료 시 / 일정 시간 후 …)
  3. **대상·위치 지정** — 누구에게·어디에 (맞은 대상, 그 뒤, 주변, 시전자 …)
  4. **상태/누적값** — 변하는 숫자를 기억·참조 (콤보 카운터, 흡수한 피해, 차지량 — 효과 수치가 이 값을 참조해 스케일)
  - 검증 예시: "그림자 단검" = `투사체(단검)` →[명중 시]→ `순간이동(대상=맞은 적, 위치=그 뒤)`. "피해 흡수 반격" = `흡수 상태(피해를 저장값에 누적)` →[종료 시]→ `데미지 방출(=저장값)`. "콤보 마무리" = `누적값(콤보)` 비례 마무리기.

### 2.5.1 기본 클래스 구상 (진행 중)

**전사 (힘)** *(구상 중)* — 근접 물리. 하위 스탯(공격/인내) 투자로 가지가 갈림:
- **공격 몰빵 → 차징 특화 가지**: 폭발적 한 방. **홀드 차징**(꾹 눌러 충전 → 떼면 강타). *잠정.* **무기 (전부 공격 24 요구), 무기별 특화:**
  - **대검** → 차지 공격 보너스 (차징 정석, 단일 폭딜)
  - **큰 망치** → 기절 + 넉백 (제어)
  - **대부** → 광역 휩쓸기 (다수전)
  - 열린 점: 홀드 차징의 단조로움 보완(차징은 시그니처 강타에만 + 나머지 즉발 / 탭·홀드 분기 / 차징 단계별 효과 / 차징 중 이동) — 추후.
- **공격 + 인내 → 보편적/정통 전사 가지**: 균형 잡힌 근접 전투. 특별한 기믹 없이 딜·맷집 적당한 "기본기"형. 입문·만능. **무기 (방패는 오프핸드 별도 칸; 클래스 무기 판정은 메인핸드 기준), 무기별 특화:**
  - **검** → 기본 올라운더 + 공격력 소폭 보너스
  - **창** → 긴 리치 + 관통
  - **한손 둔기** → 약한 기절 (큰 망치의 라이트 버전)
  - **한손 도끼** → 방어력 무시율 (적 방어를 일정 비율 관통, 단단한 적에 강함)
  - **소형 방패(오프핸드)** → 방어 역할 (요구·효과 추후)
- **인내 몰빵 → 반격형 탱커 가지 (패링 스택형)**: 정확한 타이밍 막기=패링 성공 → 무피해 + **반격 스택 +1**, 스택 쌓일수록 반격 강화(또는 일정 스택에서 강력 반격기). "정확히 막을수록 되돌려줄 한 방이 커진다." 패링의 실력 손맛 + 스택의 누적 쾌감. 솔로에도 손맛 좋음. **무기(메인=찌르기 무기 + 오프핸드=방패), 특징:**
  - **랜스** → 긴 리치(+관통), 창과 유사. (카운터 찌르기 등 능동 반격은 스킬 레이어로.)
  - **건랜스** → 평소 찌르기 + **홀드 시 좌클릭 = 포격(폭발 사격)**.
  - **대형 방패** → 왼손(오프핸드) 방패, 방어 담당 (무기 특징 X). ※ 쌍방패(양손 방패)는 제외 — 메인 무기 없이 반격 불가라 구조에 안 맞음.
- 무기(예정): 검(균형) · 도끼(위력) · 둔기(충격).

**민첩 (도적/궁수)** *(구상 중)* — 하위 스탯(신속/숙련) 투자로 가지가 갈림. **공유 무기: 단검** (세 갈래 공통, 요구=신속+숙련 합 24, 특징=이동속도 보너스):
- **신속 몰빵 → 극한의 암살자 가지**: *이동기 자체가 공격*. **돌진 관통**(적을 꿰뚫으며 벰) + **순간이동(블링크)**(기습·이탈)을 함께 운용. 콤보: 순간이동 기습 → 돌진 관통 → 순간이동 이탈. 속도=공격이자 회피, 미끄러지듯 누비며 벰. **무기: 단검(공유, 이동속도 보너스, 짧은 리치) · 쿠나이(백어택 데미지 보너스, 짧은 리치; 요구=신속 단일).**
  - 참고: "기동 카이팅 궁수" 안도 나왔으나 신속=극한 암살자로 결정. **도적은 근접 중심 — 원거리/궁수는 접음**(추후 필요하면 재검토).
- **신속+숙련 → 정통 로그 가지**: 기동성+공격속도 균형. 기믹 없이 치고 빠지며 꾸준히 싸우는 만능 스키미셔. 입문·만능(전사의 "보편 전사"에 대응). **무기: 레이피어(긴 리치 찌르기 — 단검보다 한 발 멀리) · 단검(공유).** (도적은 근접 중심 — 원거리/궁수는 접음. 무기 공유 원칙: 단검을 암살자·정통 로그 공용, 갈래는 스탯 빌드로 구분.)
- **숙련 몰빵 → 콤보형 가지**: 적에게 붙어 빠른 연타로 **콤보 카운터 누적**(끊기면 리셋) → 마지막에 누적 콤보를 **마무리기로 폭발**(콤보 수 비례). 기동성 대신 지속 콤보 화력. "안 끊고 쌓아 터뜨린다." **무기: 한손 쇠뇌(연사형 소형 석궁) + 단검(공유)** — 사격·베기를 엮는 근접 콤보(거리 벌리는 카이팅 아님).
  - **한손 쇠뇌 특징 = 원거리↔근거리 상호 버프:** 사격 시 → 아주 짧게 *근거리 데미지 버프*, 근접타 시 → 아주 짧게 *원거리 데미지 버프*. 번갈아 쳐야 둘 다 유지 → "쏘고 베고" 위빙을 메커니즘으로 강제. (버프 지속 짧음.)

**마법사 (지능)** *(구상 중)* — 하위 스탯(마력/제압) 투자로 가지가 갈림. 마나는 자원(전체 지능 비례):
- **마력 몰빵 → 폭발 누커 (영창형) 가지**: *느린 영창 + 강한 한 방*. 고위험(영창 중 무방비·느림)·고보상(압도적 단일 화력). 전사 차징형의 마법 버전. 영창 안정성·위치 선정·엄호가 묘미. **무기: 큰 지팡이(대형 스태프) → 특징: 마나 소모량 비례 마법 데미지 증가**(마나 많이 쓰는 큰 마법일수록 위력↑).
- **마력+제압 → 보편 마법사 가지**: 화력+제압 균형, 두루 쓰는 정통 캐스터(보편 전사·정통 로그에 대응). **무기: 완드(단독) → 특징: 마나 소모량 감소**(효율적으로 자주 시전). (큰 지팡이와 정반대 결.)
- **제압 몰빵 → 컨트롤러 (지속·소모전형) 가지**: 적에게 디버프·저주·도트를 겹겹이 깔아 *말려죽이고*, 자신·아군엔 버프를 둘둘 둘러 버팀. 효과 지속시간↑로 한번 건 게 오래감. 장기전·보스에 강, 순간 폭딜 약. (누커의 정반대.) **무기: 마도서(그리모어) → 특징: 디버프·버프 지속시간 증가**(건 효과가 더 오래감).

**하이브리드 줄기 (공개 — 교차 스탯 투자로 열림)** *(구상 중)*

**트리 구조 = 삼각 방사형.** 가운데(시작점)에서 STR·DEX·INT 세 갈래로 뻗음. *순수 빌드 = 한 꼭짓점 끝*, *하이브리드 = 두 꼭짓점 사이(변)에 걸침*. 하이브리드는 **공개**(히든 아님).
```
        STR
      /      \
[마검사]    [궁수]
공격+마력   공격+신속
  |            |
 INT ──────── DEX
      [DEX↔INT]
```
- **힘↔민첩 = 궁수 (공격+신속)**: 강한 화살(공격=물리 위력) + 카이팅(신속=기동). "강하게 쏘고 빠르게 빠진다." 무기: **활 · 석궁** (도적에서 뺀 원거리가 여기 정착). ✅
  - **활** → ① **무빙샷**(당기는 동안 이동 둔화 제거 → 전속력 카이팅 사격) ② **오버차지**(만충 이후 더 당기면 데미지 추가).
  - **석궁** → ① **적중 시 장전 속도 증가** ② **방어 무시율**.
- **힘↔지능 = 마검사 (공격+마력)**: 검으로 베며 마법을 두름, 물리·마법을 엮음. 무기: **마검(마력 깃든 검) / 검 + 마도서(오프핸드).** ✅
  - **마검** → **평타에 마법 데미지 추가**(물리타에 마법 피해 얹힘 — 공격+마력 융합).
  - **검 + 마도서** → 추후 (일단 마검의 평타+마법 융합이 마검사 핵심).
- **민첩↔지능 = (가칭) 주술 검객/저주 도적 — 숙련+제압**: 빠른 공격(숙련)에 디버프·상태이상을 실어 순식간에 중첩, "빠른 손으로 말려죽이는" 템포 디버퍼(컨트롤러의 근접·속공 버전). 무기: **사슬낫(쿠사리가마)** — 베며 옭아맴. **특징: 적중 시 독·출혈 도트 중첩**(빠른 공격으로 DoT 순식간에 누적). 이름 추후.

**마수 / 침식 (특수 레이어 + 세계관)** *(구상 중)* — 기본 클래스가 아님. 침식이 세계관으로 상승해 일정 수준이 되면 3개 기본 클래스 위에 마수화(변신)가 열리는 *별도 레이어*. 변신 메커니즘(§2.4)은 유지.

**세계관 (침식):**
- **배경 = 평범한 세계에 막 닥친 재앙.** 멀쩡하던 세계(바닐라 같은)에 침식이 **갑자기 나타나** 번지기 시작 (기원 불명 — 미스터리 자체가 분위기, 추후 코어에서 실마리 줄지 미정). 아직 막을 희망 있음.
- **시작 지점 = 동굴 속, 거대한 갈라진 거석 앞에서 플레이어가 깨어남.** 플레이어 정체는 굳이 정하지 않음(기원 불명 침식과 짝 — 그냥 "너"가 거기서 눈을 뜨며 시작).
- **침식의 코어** = 세계 한 구석에 있는 감염의 근원. **모드의 최종 목표 = 코어 파괴(정화).**
- 코어를 중심으로 **침식이 바깥으로 점점 확산** → 동적인 "살아있는 세계"(코어 근처=깊은 오염 위험지대=고레벨, 가만두면 세계가 잠식됨). 플레이어는 오염지대를 뚫고 코어로 향함.
- **오염 지역 엔티티 = 침식 변이체.** ① 침식된 바닐라 몹(좀비→침식 좀비 등, 더 흉포·강함) ② 완전히 새로운 마수. **오염이 짙을수록 변이·난이도↑**(외곽=살짝 변이, 코어 근처=형체도 알아보기 힘든 흉악한 마수). → 코어로 갈수록 험해지는 난이도 곡선. **플레이어 마수화도 같은 침식** → "괴물을 사냥하다 스스로 괴물이 되어간다"(테마 일치).
- **침식 스탯 상승 = 코어 조각(파편) 흡수**(능동적 선택). 흡수하면 침식↑ + 마수화 강화(대가 동반). 안 건드리면 순수 인간, 삼키면 괴물이 되어감 → "선택한 자의 길".
- **코어 조각 출처 = 침식 계열 보스 처치 드롭.** → 보스가 핵심 콘텐츠 축(침식 조각 + 리스펙 아이템 둘 다 보스 보상). 오염지대 곳곳에 침식 보스(관문)들, 코어로 향함. (최종 보스 = *코어 자체* vs *코어를 지키는 수호 보스* — 미정, 추후 구상.)

### 2.6 무기 / 장비

- **필요 스탯 보유** (스탯이 클래스·무기·전투수치를 여는 공통 열쇠). **요구는 하위 스탯**(1차 아님).
- **요구치 원칙:**
  - **공유/기본 무기** = 그 클래스 두 하위 스탯 **합 24** 요구 → 어떤 빌드든 8레벨이면 사용 (예: 도적 단검=신속+숙련 합24, 전사 검=공격+인내 합24, 마법사 기본=마력+제압 합24).
  - **몰빵 특화 무기** = 단일 하위 스탯 요구 (예: 차징 무기 = 공격 24).
  - 하이브리드 무기 = 두 *서로 다른 우산*의 하위 스탯 요구 (예: 마검=공격+마력, 사슬낫=숙련+제압, 활=공격+신속).
  - 스케일 기준: 레벨당 3p → 8레벨=24p, 10레벨=30p.
- 미달 시 = **사용은 가능하나 페널티 (소프트)**. 페널티 형태는 추후 밸런싱.
- **클래스 연계**: 클래스마다 어울리는 무기 *종류*가 있고, 그 무기를 들어야 스킬 사용 가능(§2.7).
- **장비 = 2차 스탯 옵션 제공자.** 장비가 2차 스탯 옵션을 달고 나옴 (첫 항목: **쿨감**. 향후 치명타·저항 등). 데이터팩으로 장비별 옵션 정의.
  - → "2차 스탯/장비 옵션 층"(공격력·체력·속도 같은 1차 파생 + 쿨감·치명·저항 등 장비 옵션)이 1차 능력치·장비·스킬·(추후)몹이 공유하는 계기판.

### 2.9 무력화(스태거) 시스템

- **모든 공격에 "무력화 수치", 모든 몬스터에 "무력화 게이지".** 공격으로 게이지를 깎음.
- 게이지를 **다 깎으면 → 딜타임 발동 = 적 "행동 불능"** (피해 증폭은 없음, 안전하게 몰아칠 시간).
- **게이지 회복 없음** (깎은 만큼 누적 보존 → 길게 싸워도 진행도 유지). 단 **무력화 발동 시 게이지 초기화** (다음 무력화는 처음부터 다시 깎아야).
- **무기 연계:** 둔기류(큰 망치·한손 둔기) = 무력화 수치 높음(빨리 무너뜨림), 빠른 무기(단검·콤보) = 한 방당 낮지만 빠르게 누적. → 기존 "기절·넉백" 같은 흩어진 효과를 *무력화 시스템 하나로 통합*.
- (미정) 무력화 수치가 특정 스탯과 연동될지, 딜타임 길이, 보스의 큰 게이지 등 — 추후.

## 3. 첫 구현 슬라이스 (스탯 코어 최소 수직 슬라이스)

> 하이브리드 배선 전체를 한 번 관통하는 최소 루프. 나머지는 데이터/모듈로 확장.

1. 데이터팩이 1차 능력치 1개 정의 (예: 힘)
2. 플레이어가 그 값을 보유 (Data Attachment, 영속·재접속 유지)
3. 데이터팩이 파생 규칙 1개 정의 (예: 힘 1당 공격력 +0.5)
4. 값을 바꾸면 실제 공격력 변화 (임시 명령어 `/ark stat set|get`)
5. 클라이언트 동기화 + 최소 확인 수단

**이번 슬라이스에서 제외**: 레벨·포인트 투자, GUI, 커스텀 Attribute 풀, 몹 적용.

### 모듈 경계(안)

`stat`(레코드+Codec) · `registry`(데이터팩 레지스트리) · `player`(Attachment 저장) · `engine`(재계산·적용, 단위 테스트 대상) · `net`(동기화) · `command`(개발용)

## 5. 결정 로그 (요약)

- 모드 로더 = NeoForge / 버전 = 1.21.x / 데이터팩 주도
- 핵심 경험 = 전투·스킬 중심 + 살아있는 세계
- 첫 슬라이스 = 스탯 코어
- 스탯 엔진 = 하이브리드
- 1차 능력치 = 힘·민첩·지능 + 독자 스탯 **침식**(감염 수용/마수화)
- 기본 스탯 = 힘·민첩·지능 **3개**. 침식은 기본 스탯에서 제외 → 별도 특수 스탯(세계관으로 상승, 추후 설계).
- 스탯 세분화 = 힘→공격/인내, 민첩→신속/숙련, 지능→마력/제압. **포인트 투자 대상 하위 6종**(침식 제외). 마나는 하위 스탯에서 분리=자원(전체 지능 비례).
- 능력치 값 = 정수, 우선 플레이어 적용 (엔진은 엔티티 일반 염두)
- 성장 = 레벨업 포인트(3/레벨), 경험치 영구
- 리스펙 = 가능(퀘스트/보스 보상 아이템)
- 마나 = 보편 보유+지능 증폭, 전투 외 재생
- 마수화 = 발동 토글, 허기 유지, 사냥 회복, 침식 스케일
- 클래스 = 명시적(Model A), **기본 3개(전사·도적/궁수·마법사)**, 가지치기 트리(하위 스탯으로 분기, 각 3갈래=9빌드), 스탯 문턱 해금, 택1, 변경은 리스펙, 클래스→무기→스킬
- 마수/침식 = 4번째 클래스 아님. 침식(세계관으로 상승)이 일정 수준이면 3클래스 위에 마수화 레이어 개방(추후 설계).
- 히든 클래스 = 비밀 조건 발동(영구 해금)+스탯 요구치, 발동 시 전환 택1
- 스킬 획득 = 3계층(클래스 트리 / 책 숨겨진 스킬 / 히든 클래스 스킬), 데이터팩 정의·마나 소모
- 무기 = 필요 스탯(하위 스탯 요구), 소프트 페널티. 차징 무기=공격 24.
- 클래스 선택 = 10레벨, 해금 최소 문턱 ≈ 한 스탯 20(8레벨 도달 가능). 레벨당 3p, 10레벨=30p 스케일 기준.
